# Security policy

Please report security issues privately to Armorer Labs at
`dev@armorerlabs.com`.

Do not open a public issue for vulnerabilities, authentication or transport
bypasses, token replay, cross-tenant behavior, or sensitive-data handling until
Armorer Labs has investigated and coordinated a fix.

Include the affected SDK version or commit, language and platform, deployment
transport, minimal reproduction, and expected versus actual behavior. Do not
attach customer data, credentials, signing keys, private policies, runtime
artifacts, or reviewer traces.

This repository covers the public integration SDKs. Reports about a separately
provisioned Guard runtime should also use the private reporting address above.
